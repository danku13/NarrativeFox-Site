# NarrativeFox — маркетинговый сайт

Публичный лендинг NarrativeFox — агентской системы продвижения. Следующий шаг
воронки после материалов в Top of the Funnel (vc.ru, Telegram и другие
источники): подтвердить экспертизу, просто объяснить, как работает система,
и перевести читателя на прямой контакт с основателем.

- Домен: <https://narrativefox.tech>
- Telegram: [@danku13](https://t.me/danku13)
- Почта: danku13@yandex.ru

## Структура страницы

Hero с позиционированием → полоса цифр → боли рынка (01) → что делает система,
блок «почему это не текст из нейросети» с примером до/после и каскад
«доверие → действие → сделка» (02) → четыре фазы работы без раскрытия
внутренней механики (03) → честные границы системы (04) → целевые
сегменты (05) → экономика (06) → шаги после первого контакта (07) →
финальный CTA с подписью основателя.

## Дизайн

Editorial-стиль по пресету `60-styles/editorial.md` библиотеки
[ui-for-agents](https://github.com/danku13/ui-for-agents): бумажный фон,
серифный дисплей (Playfair Display) + гротеск для текста (Inter), hairline-разделители
вместо карточек, нумерованные секции, один тёплый акцент.

Цвета взяты из дизайн-токенов продукта NarrativeFox: чернила `#1a2233`
(--g-900), приглушённый текст `#5a6470` (--k-muted), оранжевый акцент
`#d97706` (токен provenance «research» / --k-warn, тинты #fffbeb / #fde68a) —
только на путях чтения: номера секций, кавычка, маркеры, ссылки.

## Стек

- Next.js 16 (App Router), TypeScript, React 19
- Tailwind CSS 4 + собственный editorial-слой в `src/app/globals.css`
- Шрифты через `next/font/google` (кириллица), без внешних запросов в рантайме
- Без базы данных и клиентского состояния — статичная страница

## SEO и домен

- `metadataBase`, canonical, Open Graph (og:image 1200×630 — `public/og.png`),
  Twitter Card, JSON-LD `Organization` — в `src/app/layout.tsx`
- `src/app/sitemap.ts` → `/sitemap.xml`; `public/robots.txt` ссылается на него
- `src/app/apple-icon.png` (180×180) и `src/app/icon.svg` — фавиконы
- Все абсолютные URL ведут на `https://narrativefox.tech` (константа
  `SITE_URL` в `src/app/layout.tsx`)

## Аналитика (Яндекс.Метрика)

Код не грузит ничего, пока при сборке не задан номер счётчика:

```bash
NEXT_PUBLIC_YM_ID=12345678 bun run build   # локально
# на Vercel: Settings → Environment Variables → NEXT_PUBLIC_YM_ID
```

Клики по контактам помечены `data-goal="tg-click"` / `data-goal="mail-click"`
(шапка, hero, мягкий CTA в секции 03, финальный блок, подвал) и уходят в
Метрику как цели `reachGoal`. После создания счётчика добавьте в интерфейсе
Метрики две цели с идентификаторами `tg-click` и `mail-click`.

## Подключение домена narrativefox.tech

Домен зарегистрирован у REG.RU (сейчас на парковке, NS `ns1/ns2.reg.ru`).

**Вариант A — Vercel (рекомендуется):**

1. Импортировать репозиторий в проект Vercel (Next.js подхватится нативно).
2. Settings → Domains → добавить `narrativefox.tech` и `www.narrativefox.tech`.
3. В панели DNS у REG.RU вместо парковки поставить:
   - `A` запись `@` → `76.76.21.21`
   - `CNAME` `www` → `cname.vercel-dns.com`
   (точные значения Vercel покажет при добавлении домена)
4. Дождаться сертификата и www-редиректа (Vercel делает сам).

**Вариант B — свой сервер:** `bun run build` + `next start` (или standalone)
за обратным прокси nginx/Caddy, A-запись домена → IP сервера.

После подключения проверить превью ссылки в Telegram (картинка og.png);
Telegram кэширует OG-данные — при смене картинки менять имя файла.

## Раунд валидации (ноябрь 2026)

Лендинг прошли ревью 9 ролей (CMO, PMM, SMM, владелец малого бизнеса,
архитектор, эксперт по агентной разработке, техлид, TPM, Head of Product)
с фокусом на рынок РФ. Основные правки по итогам:

- H1: «Рой агентов» → «Система ИИ-агентов» (у нефактовой аудитории «рой»
  читался как «рой ботов»); кикер переведён в понятную категорию
  «контент-маркетинг под ключ».
- Добавлен блок «Почему это не „ещё один текст из нейросети“»: связка
  факты → драматургия → анти-ИИ-редактура и иллюстративный пример до/после.
- Убраны жаргонизмы («канальная сетка», «цифровой след», «проходной балл»),
  унифицированы термины и цифры (15–30 минут, «подтверждено/предположение»).
- «200 тыс экономии» → честная разница «220–235 тыс ₽» + абзац, почему
  вилка ниже штатной команды.
- Сегмент CMO переформулирован из «замены команды» в «мощность без найма».
- Шаг «Решение» отвязан от метрики заявок (ссылка на горизонт 2–3 месяца),
  SLA ответа — «в течение рабочего дня».
- Инвариант подтверждения усилен: «после вашего „да“ выходит ровно тот
  текст, который вы видели».
- Техника: og:image + canonical + metadataBase + sitemap + JSON-LD,
  Apple-иконка, контраст `sup` и hover-кнопки по WCAG AA, `scroll-margin`
  под залипающий хедер, skip-link, reveal-анимации больше не прячут
  контент при сбоях JS, настоящий курсив Playfair, каркас Метрики.

### Открытые решения за владельцем (внесены не были — нужны факты)

- Рамка пилота: длительность, платность, состав цепочки, что остаётся
  клиенту при расхождении.
- Доступы к каналам и обращение с данными: модель минимальных прав,
  хранение записей разговора и базы фактов, 152-ФЗ, выгрузка при
  завершении.
- Юридический блок: ИП/ООО, работа по договору, безнал.
- Собственные proof-артефакты: скрин карты публикаций, фрагменты
  реальных текстов, ссылка на канал, который ведёт система.
