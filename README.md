# NarrativeFox — маркетинговый сайт

Публичный лендинг NarrativeFox — агентской системы продвижения. Следующий шаг
воронки после материалов в Top of the Funnel (vc.ru, Telegram и другие
источники): подтвердить экспертизу, просто объяснить, как работает система,
и перевести читателя на прямой контакт с основателем.

- Telegram: [@danku13](https://t.me/danku13)
- Почта: danku13@yandex.ru

## Структура страницы

Hero с позиционированием → полоса цифр → боли рынка (01) → что делает система
и каскад «доверие → действие → сделка» (02) → четыре фазы работы без
раскрытия внутренней механики (03) → честные границы системы (04) → целевые
сегменты (05) → экономика (06) → шаги после первого контакта (07) →
финальный CTA.

## Дизайн

Editorial-стиль по пресету `60-styles/editorial.md` библиотеки
[ui-for-agents](https://github.com/danku13/ui-for-agents): бумажный фон,
серифный дисплей (Playfair Display) + гротеск для текста (Inter), hairline-разделители
вместо карточек, нумерованные секции, один тёплый акцент.

Цвета взяты из дизайн-токенов продукта NarrativeFox: чернила `#1a2233`
(--g-900), приглушённый текст `#5a6470` (--k-muted), оранжевый акцент
`#d97706` (токен provenance «research» / --k-warn, тинты #fffbeb / #fde68a) —
только на путях чтения: номера секций, кавычка, маркеры, ссылки.

## Стек

- Next.js 16 (App Router), TypeScript, React 19
- Tailwind CSS 4 + собственный editorial-слой в `src/app/globals.css`
- Шрифты через `next/font/google` (кириллица), без внешних запросов в рантайме
- Без базы данных и клиентского состояния — статичная страница

## Разработка

```bash
bun install   # или npm install
bun run dev   # http://localhost:3000
```

Проверка кода: `bun run lint`.

## Публикация

Любой хостинг Next.js (Vercel — без конфигурации) или статический экспорт.
Перед деплоем обновите `openGraph.url` и домен в `src/app/layout.tsx`.
